# ULTIMATE: BREAKPOINT

A Roblox ultimate frisbee game built around a deep movement-tech system:
snap cuts, momentum cancels, fake commits, burst steps, slide cuts, air
redirects, precision landings, layouts, recovery chains and wall rebounds,
plus a fully simulated, controllable disc (backhand, forehand, hammer,
scoober, blade; bank, release height, timing). It's real ultimate underneath:
pulls, no running with the disc, stall counts, turnovers, Callahans and
the Greatest.

* **Design:** [`docs/DESIGN.md`](docs/DESIGN.md) covers every mechanic, number and counterplay.
* **Testing:** [`docs/TESTING.md`](docs/TESTING.md) covers what was verified and the Studio test plan.

> **Status — honest version.** The full vertical slice is written (~20k lines
> of Luau, 61 source files): movement engine, disc physics, throwing,
> catching, defense, the rules of ultimate, match loop with bots, six arenas,
> training grounds with eight drills, HUD/menus, mobile and gamepad controls,
> progression and saving. It type-checks against the real Roblox API, lints
> clean and passes 71 offline tests (including movement fuzzing and
> rule/physics integration tests). **It has not been run in Roblox Studio
> yet.** Expect some tuning and small engine-behaviour fixes on first play;
> `docs/TESTING.md` §2 is the checklist.

## Quick start

### Option A — open the place file
1. Open **`build/UltimateBreakpoint.rbxlx`** in Roblox Studio.
2. Press **Play** (F5). You spawn on the sideline during warm-up; a Casual
   match with bots starts after ~20 s (press **M → Play → START MATCH NOW** to
   skip, since in Studio you are the host).

### Option B — Rojo (for editing the code)
1. Install [Rojo](https://rojo.space) 7.4+ and the Rojo Studio plugin.
2. `rojo serve` in this folder, then connect from the plugin in an empty place.
3. Or build a fresh place: `rojo build default.project.json -o build/UltimateBreakpoint.rbxlx`.

### Studio settings
| Setting | Where | Why |
|---|---|---|
| Avatar type **R15** | Game Settings → Avatar (also set in the place) | poses and animations target R15 (R6 is handled but less polished) |
| **Enable Studio Access to API Services** | Game Settings → Security | saving, ranked rating, leaderboard. Without it the game runs and tells you progress isn't saved |
| Multiplayer test | Test → Clients and Servers (2–4 players) | catches, contests, marking, replication |

Place-level properties are set in `default.project.json`: gravity 160,
streaming off, Future lighting, shift-lock off (Shift is sprint), default walk
speed/jump 0 (the movement engine drives characters).

### Required Roblox objects
**None to build by hand.** At runtime the server creates:
`ReplicatedStorage.UBRemotes` (remotes), `UBState` (match attributes), `UBDiscs`
(one Configuration per disc), the `Teams` (TIDE, BLAZE, SIDELINE), the arena
model, the Training Grounds hall, `Workspace.UBBots` and the collision groups
`UBPlayers` / `UBLimbs`. Clients create `Workspace.UBVisuals` (local disc and
effect visuals) and the `UBInterface` ScreenGui.

## Controls (defaults, all rebindable in Menu → Controls)

| | Keyboard/mouse | Gamepad | Touch |
|---|---|---|---|
| Move · sprint | WASD · hold Shift | left stick · L1 | stick (push fully) · SPRINT |
| Jump · Cut · Slide · Dive · Burst | Space · Q · Ctrl/C · E · F | A · X · B · Y · R1 | buttons |
| Reach, or hold to throw | LMB | R2 | THROW/REACH |
| Mark stance, or fake | RMB | L2 | FAKE/MARK |
| With disc: bank · type · low · hop · lead assist | Q/E · 1–5, Z/X, wheel · Ctrl · Space · R | D-pad · B · A · R3 | BANK · TYPE · LEAD |
| Menu · mouse lock · celebrate | M · LeftAlt · B | Select · — · D-pad down | MENU |

New players: walk into the disc to catch it, hold and release LMB to throw.
**Menu → Training → Movement School** teaches every technique in order.

## Stage report

### Stage 1 — Mechanics design ✅
Movement state machine, momentum model, technique windows/costs/counterplay,
disc flight model, catching rules, balance constraints.
*Files:* `docs/DESIGN.md`, `src/shared/Config/*`.

### Stage 2 — Architecture ✅
Client/server split, remotes, replicated state, shared modules.
*Files:* `src/shared/Net.luau`, `Actors.luau`, `src/*/Main.*.luau`, DESIGN §11.

### Stage 3 — Playable vertical slice ✅ (code complete, Studio-untested)
Field, two teams, responsive movement, controllable disc, throwing,
catching, interceptions, scoring, possession resets, match loop, HUD, bots.
*Test:* TESTING §2 A.

### Stage 4 — Advanced movement ✅
All techniques, chains, feedback, cooldowns, combo evaluation, training
tools. *Test:* TESTING §2 B–C. Offline: `tests/movement_spec.luau`.

### Stage 5 — Complete sport ✅
Five throw types + modifiers, fakes, lead assist, mark stances, hand blocks,
stall/double-team/disc-space, pulls, Callahan, Greatest, time cap, universe.
Offline: `tests/rules_spec.luau`, `throw_spec.luau`, `catch_spec.luau`.

### Stage 6 — Polish and expand ✅ (first pass)
Six arenas + a Rebound variant, progression, cosmetics, achievements,
ranked rating + leaderboard, Rush and Clutch modes, private-server rules,
effects, crowd, audio hooks, procedural animation, mobile/gamepad.

### Stage 7 — Test and optimise 🔶 partially done
Done offline (see TESTING §1). **Remaining:** run TESTING §2 in Studio,
tune feel with real players, profile.

### Not done yet (next steps)
* Cross-server ranked **matchmaking** (MemoryStore queue + reserved servers).
  Today "Ranked" is a server mode chosen by vote with rating updates.
* Freestyle, King of the Field and Tournament modes; replays.
* Authored animations and audio. Today poses are procedural and sounds are
  engine built-ins, with crowd-loop slots left empty for your own uploads.
* Bots don't use movement techniques beyond jumping and diving.
* Contact fouls aren't modelled (players don't collide).
